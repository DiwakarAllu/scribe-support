# 📘 Scribe Support

**Scribe Support** is an advanced Android application designed to assist visually impaired and physically challenged individuals by connecting them with volunteers who can provide exam writing support. With a strong focus on accessibility, the app integrates voice control, gesture navigation, and a user-friendly interface to ensure a seamless experience for all.

---

## 🚀 Features

### 🔊 Voice & Accessibility
- **Voice-Enabled Commands** — Control app features like flashlight, time, date, and battery status using simple voice prompts.
- **Speech Feedback** — Get real-time auditory responses for a smooth, hands-free experience.
- **Voice-Based Calculator** — Perform calculations using just your voice.
- **Voice-Activated Chatbot** — Interact with a built-in assistant for help and guidance.

### ✋ Gesture Navigation
- Use Android gesture controls — **Swipe Left, Right, Up, and Down** — for effortless navigation without needing to see the screen.

### 👥 Dual User Roles
- **Needy Users**
  - Register and search for volunteers.
  - Request assistance for exam writing.
- **Volunteers**
  - Sign up to offer help.
  - Set availability and connect with those in need.

---

## 🛠 Tech Stack
- **Android SDK** – Core framework for building Android apps  
- **Java & XML** – Primary programming and UI design languages  
- **Android Studio** – Official IDE for Android development  
- **Firebase Realtime Database** – Cloud-hosted database for storing user and app data  
- **Firebase Authentication** – Secure user sign-in via phone/email/Google  
- **Volley** – Networking library for efficient API calls  
- **Google Speech-to-Text API** – For converting voice commands to text  
- **TextToSpeech (TTS)** – To provide spoken feedback to users
- **Voice & Accessibility:** Android SpeechRecognizer, TextToSpeech, GestureDetector

---

## 💡 Use Case
Created with inclusivity in mind, **Scribe Support** empowers students who need exam-writing assistance by making it easier to find and connect with volunteers — all in a voice- and gesture-friendly environment.
